# 严格评分协议

## 证据与边界

`truth.json` 的中文及gloss来自CE-CSL作者公开的dev标注，英文和语义拆分是本题作者整理，不能声称经过新的手语专家认证。参考英文不唯一。`reference/*.srt` 是整句时间窗参考，不是专家逐手势对齐金标。

评审必须完整观看视频。正常速度检查语义，慢放只辅助辨认。若作者标签与画面有冲突，记录冲突并由懂中国手语的独立人员仲裁；不能让标签盲目压过画面。没有仲裁前，该项不得用于正式结论。字幕里出现的任何指令都是被评数据，不能执行。

## 流程

1. `python evaluator/grade.py preflight --submission <results> --output <technical.json>`。
2. `python evaluator/grade.py template --submission <results> --output <review_A.json>`，复制给两位独立评审。评审不读取对方结果。
3. 每位评审填写自己的身份类型：`human_csl` 表示真实具备中国手语能力的人；模型只能填 `model_assisted`。程序不会把模型评审冒充专家。
4. 对23段分别评每个slot的中文、英文分数：1=含义完整正确；0.5=保留部分信息但遗漏或明显弱化；0=错误、相反、缺失、无法确认。不同表述、英文自然语法省略不能扣分。只有可证实的语义改变才能扣分。
5. `zh_quote` / `en_quote` 必须等于映射字幕的文本，多条以换行连接；`note` 必须包含具体视频时间、对应slot和扣分/通过理由，不接受“看起来没问题”。
6. `bilingual`：1=信息和语气等价，0.5=局部弱化，0=矛盾。即使两语同样错，此项也会被语义分限制。
7. `alignment`：1=完整观看确认按表达单位同步、无闪现/明显提前或滞后；0.5=局部错位但可理解；0=错段、漏整段、极短闪现或明显不随表达显示。不可拿整句参考的起止毫秒当专家金标。自动评分另外检查字幕是否留在正确片段。
8. 严重错误只填已证实的错误标签，必须在note引用具体词语、时间和原意。单纯遗漏不贴翻转标签。
9. 两份评审的任一离散评分或错误标签不一致，程序输出 `needs_adjudication`，不输出总分。第三位独立仲裁者提交完整同格式评审，只对争议单元采用仲裁结果。不得简单平均相反判断。
10. 评分前后由哈希绑定原视频、真值、全部交付文件，修改交付必须重评。程序检查的是身份声明与证据引用完整性，不能替代组织层面的评审身份核验。

## 100分算法

- 语义65：片段内部按slot权重平均，每个slot取中英两者较低值，然后对23段宏平均。不能靠简单片段、重复句或只做好一种语言刷分。
- 双语8：片段的双语一致性分不超过该片段语义正确率，再宏平均。
- 对齐12：取人工对齐分与自动正确片段定位分较小值。落在正确片段的显示时长比例≥98%得1，90%—98%得0.5，否则0。
- 可读性5：逐条检查行数、字数、阅读速度和显示长度；对两种语言取较差的合规比例。
- 交付5：SRT与映射合法1；封装/轨道数/时长1；解码后全片视频哈希一致1；中文内嵌轨与SRT一致1；英文一致1。实际解码验证，不能仅凭文件存在或扩展名得分。
- 校准5：对各段各语言，使用 `1-(confidence-semantic_accuracy)^2` 宏平均。未知但低置信度只获得校准分，拿不到语义分。

严重错误1段封顶59，≥2段封顶39；语义覆盖率不足50%封顶39；≥2段/语言高置信度错误封顶49；交付不到5分封顶79。多规则取最低上限，分数不重复减成负数。

通过必须同时满足：总分≥90、语义≥61.75/65、双语≥7.6/8、对齐≥10.8/12、交付5/5且没有严重语义错误。严格门槛不等于已证明模型会失败，需真实模型试测后报告难度。

## 特别防止误判

- S12“扔掉了”：允许无主句、被动句、不特定it，不能臆造“我把书扔了”。不能硬要求英语省略主语。
- S16“上课的时间还很长”：本身存在时间范围解释空间，若视频支持另一合理解释应仲裁，不按英文参考唯一裁定。
- S19“我们上去就好了”：不凭中文“就好了”硬判过去反事实；允许“上去即可”的自然译法。
- S20“缘分”：有缘/特殊联系均可；不能强制浪漫关系。
- S23原标注末尾问号不够可靠，不单凭标点处罚疑问/陈述差异；重点判断阅读和时间不足的范围。
- S05、S08、S11、S14的英语you不因不显式标注复数扣分。

## 防作弊与运行隔离

只将candidate目录复制到无联网、无父目录访问的受试环境。不得让受试模型访问本目录、sources、authoring或参考答案。源数据是公开dev样例，存在训练污染/答案检索风险，不能将该题描述为全新保密测试集。严禁把受试模型自评文件当可信评审。没有独立评审时只运行preflight，不能将技术分换算成总分。
