# 转写说明

本谱依据所给 performance.mp4 的自然录音与键盘画面制作，未使用出版谱或联网资料。采用钢琴双谱表，所有重复击键均写成实际音符，未使用省略反复或不可解析的颤音代替音符。

谱面以 4/4 和四分音符约 120 为阅读基准，包含开头休止；alignment.json 给出从累计四分音符位置到视频秒数的统一映射。细分音符用于保留演奏中的先后次序。此拍号与小节划分是本次转写的编辑选择，不声称是原作的拍号。

只收录起音位于 [1.230, 75.480) 秒的候选击键。片段开始前已经持续的声音不补写起音；结尾已起音的音符按谱面节奏延续。音符时值整理为可阅读的声部长度，不等同于手指释放或踏板衰减时间。左右谱表按照音区和声部走向分配，交叉手处不作严格指法指定。

分析使用多分辨率短时频谱、由本录音估计的谐波模板、短窗起音包络以及视频手部位置核对。没有使用音频播放听审；频谱检查和画面检查不等同于实际聆听。低音密集段中相邻半音、弱内声部与泛音的区分，以及快速装饰音的微小时序，仍有不确定性。没有按记忆中的作品静默修正音高。

MusicXML 为主文件；MIDI 从重新读取后的同一 MusicXML 音符及连音线时值生成，PDF 也由该 MusicXML 排版。
