# 转写说明

- 以视频时间为基准，保留 `[1.230, 75.480)` 内检测到的新击键；谱面从视频 0 秒开始，开头休止对应非评分上下文。
- 采用 4/4、120 BPM 和 1/16 四分音符量化网格（约 31 ms），密集段不省略重复击键。`alignment.json` 使用与 MIDI 恒定速度一致的时间锚点。
- 音高由录音起音附近的基频/泛音变化与俯拍键盘的手部区域共同约束；低音频段另用较长分析窗减少相邻半音混淆。
- 同时起音合并为和弦；为保持单谱表声部清晰，持续音的记谱时值最多保留一个四分音符，踏板造成的更长衰减不逐项写实。
- 这是基于实际演奏的独立转写；极快速的叠置和弦、被手遮住的键及部分弱起音仍存在不确定性，不以出版谱或曲名记忆补齐。
