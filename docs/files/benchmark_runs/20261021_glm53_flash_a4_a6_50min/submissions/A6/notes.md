# 转写说明

## 处理方法
- 以原始录音的短时能量/谱通量候选作为击键时间，不改变音视频速度；候选区间限定为 1.230–75.480 秒，右端不含。
- 音高采用键盘前后帧差定位触键横坐标，并和基频显著度候选取交集；这一步用于抑制低频机械噪声与指键噪声造成的假音高。
- 记谱速度取 129 BPM、4/4；起音量化到 1/8 四分音符（32 分音符，约 58 毫秒）。`alignment.json` 每 0.5 秒给出谱面四分音符位置到视频秒数的线性锚点，因此时间评分不依赖 MIDI tempo。
- 所有检测到的重复击键均写成独立音符，不用连音线合并；不需要计数的谱面反复已按实际时间展开。
- 音符记谱时值一般为 16 分音符，小节线前最后一格写作 32 分音符；这只表示可理解的记谱时值，起音时间由 `alignment.json` 控制。实际候选音区较高，MIDI 音高、起音和时值与 XML 合并连音线后的结果一致。PDF 使用同一事件表绘制为钢琴大谱表，密集段落采用简洁排版。

## 边界与不确定处
- 起始边界前及 75.480 秒及以后的新起音未写入；不为本应在视频前已按下的持续音补假起音。
- 快速经过句、手部遮挡和指键噪声仍可能导致个别候选漏检或音高取邻近候选；尤其密集装饰重复处比普通乐句更不确定。
- 未人工回忆或套用出版谱，也未把疑似演奏差异静默改写为“常规”音高。
- 输入来源与许可见 SOURCE_CREDIT.md；本交付只使用该 77 秒 candidate 输入和本地离线工具生成。
