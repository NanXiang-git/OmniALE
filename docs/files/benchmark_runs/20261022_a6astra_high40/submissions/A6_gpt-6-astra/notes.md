# 转写说明

依据所给 performance.mp4 的自然录音与键盘画面转写，未使用出版谱、联网资料或外部模型。

- 记谱采用 4/4、四分音符约 120；这是用于阅读和对齐的统一节拍框架，并非对原作拍号的断言。以十六分音符为主，较短经过音按三十二分音符整理，接近同时的起音合写和弦。开头保留休止。
- alignment.json 给出谱面累计四分音符 q 与视频秒数 t 的公共映射（t=q/2），覆盖全部起音；所有声部采用同一映射。
- 只记入估计新击键起音位于 [1.230,75.480) 秒的音符。边界前已有的持续音不补假起音；结尾已起音的音符允许在谱面延续。
- 反复与重复击键均展开。按音区安排两谱表，开头低谱表用高音谱号，部分高音段采用八度高音谱号；交叉手段落的谱表归属是阅读安排，不是逐指手别记录。
- 采用相邻起音间的可读时值；踏板、混响尾音与手指释放不等同于记谱时值。未逐项记踏板或指法。
- 核查手段为短时频谱、谐波分解、起音变化与键盘图像。未进行实际音频听审。快速重复、同音八度叠加、低音共鸣及手指遮挡处仍有不确定性；尤其约 50–66 秒的低音声部和快速经过音需要后续演奏者复核。

来源：PianoVAM v1.2；Yonghyun Kim、Junhyung Park、Joonhyung Bae、Kirak Kim、Taegyun Kwon、Alexander Lerch、Juhan Nam（2025）。本转写为所给节选的衍生整理，保留 CC BY-NC 4.0 来源许可与非商业用途说明。

自检：重新解析最终 MusicXML，合并延音连线后共 1,094 个音符、38 小节；标准 type 1 MIDI 的音高、四分音符起点和时值逐项一致（PPQ 10080）。对齐锚点的范围、间距和斜率已检查。最终 PDF 共 5 页，已逐页查看渲染图，修复了转换缩放与页眉裁切问题。这些检查不等同于与参考答案比对或实际听审。
