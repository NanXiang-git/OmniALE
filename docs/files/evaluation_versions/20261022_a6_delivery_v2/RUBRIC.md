# A6 v2：可用交付导向的分级评分

这是经用户授权，在观察历史答卷后制定的事后复评标准，不是答题前预注册标准。统一应用到 deliverables 中全部 A6 历史提交；不重跑模型，不修复答卷，不改动原 v1 记录。基础设施阻断且未产生答卷的记录维持未评分。

## 权重与计算

|项目|分值|方法|
|---|---:|---|
|全局音高/起音|20|相同音高、200ms 容差的逐音 F1|
|全段覆盖|7.5|六个时间段的 F1 宏平均|
|音区覆盖|7.5|低、中、高三个音区的 F1 宏平均|
|精确起音|20|相同音高、80ms 容差的 F1|
|MIDI/XML 一致性|10|原始两个文件的音高、拍位及时值一致性 F1|
|PDF 可读性|15|逐页检查谱号、音头、变音、符梁、间距、裁切|
|记谱可演奏性|15|拍位、休止、声部、时值、连结关系是否可直接理解|
|PDF/XML 忠实完整性|5|首中尾、全部页面/谱表，是否呈现同一份音乐内容|

先求加权原始分，再乘交付等级系数。各档不是在模型间按排名分配，也不设置保底分；证据相同时同分。不得为避免零分虚构能力。

## 交付等级：按最严重的已证实问题取一档

* **完整可用 ×1**：四件套可打开，PDF 音乐符号可辨，拍位/声部可理解，各格式内容一致，只有局部排印问题；视觉三项均至少 0.75，MIDI/XML 一致性至少 0.95。
* **需大幅修订 ×0.6**：格式齐全、音乐内容一致且总体可解读，但跨拍写法、复杂细分、声部组织等需要实质编辑；或存在有限的跨格式误差。一致性低于 0.95 但不低于 0.8 也最多此档。
* **不可用或实质不一致 ×0.25**：PDF 系统性缺音头/谱号/变音，严重叠压裁切，关键休止/拍位系统性不表达，或 PDF 与 XML 中/尾段不是同一组音乐；MIDI/XML 一致性低于 0.8 也最多此档。即使 XML 可恢复，也不能视作 PDF 合格。此档最高 25 分，保留转写技术差异。
* **缺关键交付 ×0.1**：PDF、非空可解析 XML、非空可解析 MIDI 任一缺失/损坏，但仍有可评价音乐内容。最高 10 分。仅 notes.md 缺失/不说明节拍、时值及不确定性时最多“需大幅修订”。
* **无可评内容 ×0**：实际作答后没有非空可评音乐内容。未启动/基础设施阻断不算空交付，维持 null。

不把孤立的标题/速度字形问题当成全谱不可用。不因换页、等音异名、左右手分配或不同合理记谱风格扣分。不以独立渲染器自身的故障惩罚原提交。

## 视觉项统一锚点

每项只用 0、0.25、0.5、0.75、1 五档，附页面/小节证据。

* 可读性：1 全篇清晰；0.75 局部瑕疵仍可读；0.5 多处拥挤须明显放大；0.25 仅部分可辨、严重缺损；0 无法可靠读出音高/节奏。
* 可演奏性：1 节拍/声部表达自然明确；0.75 有少量生硬写法；0.5 结构可恢复但反复细数/重排；0.25 系统性丢失休止或拍位，需重建；0 无法确定连贯演奏。可以参考可编辑谱判断可恢复结构，但等级系数始终针对实际完整交付。
* 忠实完整性：1 未发现实质不一致；0.75 局部非关键缺漏；0.5 有限但影响理解的差异；0.25 大量差异只保留部分对应；0 系统性漏关键符号、漏页/声部或不同音乐内容。逐系统查看并重点核对首中尾，不宣称图形逐音穷尽验证。

## “可交付合格”的底线

60 分以上必须同时满足：等级 ×1；音高精确率与召回率均至少 80%；80ms F1 至少 0.70；每个时间段及音区 F1 至少 0.60；MIDI/XML 一致性至少 0.95；视觉三项均至少 0.75。未满足则总分最多 59，避免大段漏音仍被称为合格。这是本基准的操作定义，不是音乐专家认证。

这里没有可靠的专家节奏/表情标准谱，故不新增伪精确的力度、踏板或书面时值准确率；手指离键与踏板延音不等同于应写时值。原始 MIDI/TSV 仍只作为真实击键/起音真值。

## 复评与证据

原生解析器从原文件重算客观指标。LLM 逐页查看本次 PDF 栅格图，结合旧独立评审、XML 结构、独立渲染证据作分档判断；不能把旧分数直接换算成新视觉分。记录输入 SHA256、规则 SHA256、原始指标、三项视觉分、等级原因、原始加权分与最终分。未查清的项目保留 null，不猜测。
