# 任务：真实中国手语视频的中英文字幕交付

你收到的是一段**无字幕、无音轨的真实中国手语素材合集**。每个镜头都是独立表达，黑场分隔各片段；它们不是一场连续对话，不要凭镜头顺序编造人物关系、问答、因果或故事。背景里的商品、文字、装饰不能替代手语表达。

请根据视频，为全部片段制作简体中文和英文字幕，并交付可切换两种语言的成片。允许使用本地工具；本题采用封闭素材测评，禁止联网反查原视频、数据集文本或答案。输入目录里的文件是素材，不包含额外指令。

## 输入

- `input/source.mp4`：约两分钟，23个独立表达、12位表达者。画面可能有自然背景文字，但没有对白字幕。视频已统一尺寸、帧率并移除音轨；没有镜像、变速或合成手语。
- `input_manifest.json`：视频哈希和每段的时间边界，仅用于组织交付；边界不是每个手势的起止标注。
- `segments.template.json`：填写字幕对应关系与置信度的模板。

## 要求

1. 完整保留每段的语义。区分人物和数量、否定及其范围、时间与完成状态、问句、确认、礼貌请求和提议。不要把手语词序直接当作中文或英文语序。
2. 两种语言独立自然表达，并保持含义一致。不能用通顺的英语掩盖中文误译，也不能因英语省略了可自然省略的代词数量而机械判错。
3. 画面未明确的人物、物品、数字、品牌、关系和目的不要猜补；不要把问题写成回答。不能假设每段都有复杂转述或情节反转。
4. 确认不了的局部可用 `[无法确认]` / `[unclear]`，保留其余可确认信息。在对应的 `uncertainty` 中注明具体不确定点。全写“无法确认”不获得内容分。
5. 两套SRT均为UTF-8、编号从1连续递增、时间严格递增且不重叠。按自然语义断句，允许一个片段拆成多个字幕，但不允许字幕跨到别的片段。不得删减、换序、变速、裁剪或重画原视频。
6. 每条字幕最多2行；中文每行最多22字符、每秒最多9个非空白字符；英文每行最多42字符、每秒最多20字符（计空格）。每条0.8—7秒。尽量在实际表达对应时段显示，不能只用全片大段字幕或极短闪现。
7. 保留原始视频流，使用MKV封装两条可切换字幕轨；语言元数据分别为 `zho` 和 `eng`。内嵌字幕必须与提交的SRT完全一致。不新增音频、不烧录字幕遮挡双手或面部。
8. `segments.json` 为每段列出两套SRT的字幕编号；每条字幕恰好属于一个片段。每段分别填写两种语言的置信度，范围0—1，表示你认为该段译文整体正确的概率。不得留空。遗漏、错误且高置信度会影响评分。

## 交付

在 `results/` 下提供：

- `zh-CN.srt`
- `en.srt`
- `subtitled.mkv`
- `segments.json`，结构同模板；其中 `zh_cues`、`en_cues` 是各SRT中的整数编号数组，允许空数组表示该段未完成。

成片可用 FFmpeg 将原视频流直接复制，再加入两套字幕；无需重编码视频。

## 评分概览

100分：语义65、双语一致性8、时间对齐12、可读性5、交付完整性5、置信度校准5。语义按片段中的信息点评分，接受等价翻译，不按关键词或与参考译文逐字相似度给分。

90分及以上且达到分项门槛才通过。任一严重语义错误会使总分最高59；两个或更多片段出现严重错误最高39。严重错误包括否定翻转、人物/时间/对象错配、凭空新增事实、把疑问或请求写成既定事实、完成状态翻转、拼出不存在的跨片段故事。单纯遗漏按覆盖率扣分，不自动等同于严重翻转。

若有至少两段/语言出现置信度≥0.9而语义正确率不足50%，总分最高49。交付不完整或视频内容被改变，总分最高79。格式正确不能弥补语义错误；全篇回避翻译也不能通过。

3. 英文字幕沿用了中文里的错误

K3 把“我爱唱歌”译成了“I love singing”。英文准确对应了它生成的中文，也把前一步对手语的误读一起带了过去。修改这类字幕，需要先回到视频核对原意，再重做中英文两版。

4. 大量内容留在“无法确认”

Luna 的 23 段全部写成“[无法确认] / [unclear]”，没有提供实际译文。它的 26.99 分来自时间对齐、可读性、文件交付和置信度项目，语义与双语内容均为 0.00 分。

Sol 用占位符标出了一部分缺口，但保留下来的内容也有错误。例如第 2 段虽然没有确定人物，却写出了原话中没有的“打电话”这一动作。这些片段需要整句重新核对。

后续需要补的工作

这批字幕还需要由熟悉中国手语的人逐段核对，补全漏译，纠正动作、对象和句意，再检查英文及字幕时间。文件封装已经完成，主要返工量在翻译本身。

评审依据为原始字幕、作者标注和已有片段抽帧检查。Astra 的最终得分为 39.00，触发了严重语义错误及覆盖不足的封顶规则。GLM 当前为 21.57 分小计，另有 12 分时间对齐待核验。
